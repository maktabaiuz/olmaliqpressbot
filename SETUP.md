#### Option 2: Create new Telegram API credentials
1. Go to https://my.telegram.org/apps
2. Login with your Telegram account
3. Click "Create new application"
4. Fill in the form and get API_ID and API_HASH
5. Update `.env` file with these values

## 🎯 Next Steps

### For Local Testing:
```bash
# Copy example config
cp .env.example .env

# Edit with your values
nano .env

# Install dependencies
pip install -r requirements.txt

# Test run
python main.py --test
```

### For Server Deployment:

#### With Docker (RECOMMENDED):
```bash
# On server
ssh root@server
cd /opt
git clone https://github.com/maktabaiuz/olmaliqpressbot.git
cd olmaliqpressbot

# Copy and edit .env
cp .env.example .env
nano .env

# Start bot
docker-compose up -d

# Check logs
docker-compose logs -f
```

#### With Systemd:
```bash
# On server
ssh root@server
sudo bash /tmp/setup_server.sh

# Configure
sudo nano /opt/olmaliqpressbot/.env

# Start
sudo systemctl start olmaliqpressbot
sudo systemctl status olmaliqpressbot
```

## 💡 Quick Troubleshooting

**"TELEGRAM_API_ID empty or invalid"**
→ You need to get API credentials from https://my.telegram.org/apps

**"ModuleNotFoundError: No module named 'telethon'"**
→ Run: `pip install -r requirements.txt`

**"Gemini API error"**
→ Check GEMINI_API_KEY in .env file
